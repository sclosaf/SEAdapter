Installing and Running the JDBC API Test Suite 1.2.1
The JDBC API test suite contains tests useful for testing a driver based on JDBC technology ("JDBC driver") for it's conformance to the requirements of the Java 2 Platform Enterprise Edition (J2EE). This test suite is intended to assist driver vendors in preparing their drivers for certification in a J2EE compatible configuration using the J2EE Compatibility Test Suite. We have attempted to make the JDBC API Test Suite comprehensive enough that it covers the JDBC requirements tested by the J2EE CTS.
